## [0.1.0] — 2025-08-04

### Added
- Panel general con métricas de ventas y gráfico de los últimos 30 días (Recharts)
- Módulo de Pedidos con filtros por estado y cambio de estado con un clic
- Módulo de Clientes con búsqueda y ficha con historial de compras
- Módulo de Productos con CRUD completo y alerta visual de stock bajo
- Pantalla de login decorativa
- Seed automático con 15 productos, 20 clientes y 60 pedidos realistas
- Dockerfile para deploy en Dokploy / cualquier host de contenedores
- Docker Package publicado en `ghcr.io/lykos-software-solutions/vendra`
- CI con GitHub Actions (lint + build en cada push)
- README bilingüe con badges y documentación completa
