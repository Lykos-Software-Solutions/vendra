# Contributing to Vendra

Thanks for your interest! Vendra is a **demo/portfolio showcase** developed by [Lykos Software Solutions](https://lykos.com.ar). Here's what that means for contributions:

## Scope of this demo

This repo shows what a real order management system looks like with:
- Next.js 16 App Router + Server Actions
- Prisma + SQLite
- Tailwind CSS v4 + Recharts

The login screen is **decorative** — there is no real authentication by design, as this is a demo.

## What PRs are welcome

- 🐛 Bug fixes
- 📖 Documentation improvements
- ♿ Accessibility improvements
- 🌐 i18n / translations
- 🧹 Code quality improvements

## What PRs are out of scope

- Adding authentication (contact us for the full product)
- Switching databases
- Major feature additions that go beyond the demo scope

## How to submit a PR

1. Fork the repo
2. Create a branch: `git checkout -b fix/your-fix-name`
3. Make your changes and commit: `git commit -m "fix: description"`
4. Push and open a Pull Request against `main`
