# Security Policy

## Supported Versions

Vendra is a **demo/showcase project** maintained by [Lykos Software Solutions](https://lykos.com.ar).
Only the latest version receives security updates.

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Send a detailed report to: **hola@lykos.com.ar**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We'll respond within 5 business days and coordinate a fix before any public disclosure.
