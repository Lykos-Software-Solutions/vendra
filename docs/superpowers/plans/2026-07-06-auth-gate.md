# Gate de autenticación real — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar el login decorativo por autenticación real: cookie HMAC-SHA256, middleware, guards en páginas y actions, fail-closed en producción.

**Architecture:** Réplica del mecanismo de Solvia en tres capas: `lib/auth.ts` (núcleo agnóstico del runtime, Web Crypto), `lib/guard.ts` (server-only: cookies + redirect), y `proxy.ts` en la raíz (primera barrera de ruta). Defensa en profundidad: cada página del panel y cada server action re-chequean la sesión. La cookie es `"<expiraMs>.<hmac>"` firmada con `SESSION_SECRET` (fallback `ADMIN_PASSWORD`).

**Tech Stack:** Next.js 16 App Router (proxy/middleware edge + server actions), Web Crypto API, Prisma (sin cambios de schema).

**Spec:** `docs/superpowers/specs/2026-07-06-auth-gate-design.md`

## Global Constraints

- Copy de UI en español rioplatense (voseo). Sin dependencias nuevas.
- Contraseña demo publicada: `vendra2026`. Cookie: `vendra_sesion`. TTL: 7 días.
- Fail-closed: en `NODE_ENV === "production"` el gate SIEMPRE está activo; sin `ADMIN_PASSWORD`, nadie entra. En desarrollo, activo solo si `ADMIN_PASSWORD` está definida.
- `lib/auth.ts` NO puede importar `next/headers`, `next/navigation` ni nada de node — solo Web Crypto (`crypto.subtle`), para correr en el runtime edge del proxy.
- Comparaciones en tiempo constante para firma y contraseña.
- Verificación: `npm run build`, `npm run lint` (solo la warning preexistente de `.remember/`), scripts e2e con `playwright-core` del scratchpad (`chromium.launch({ channel: "chrome", headless: true })`). `$SCRATCH` = scratchpad de la sesión. Servidores: matar residuos en 3111 antes (`lsof -ti:3111 | xargs kill`).
- Los e2e existentes (`e2e-pedidos.js`, `e2e-tema-base.js`, `e2e-tema-toggle.js`) deben seguir verdes SIN tocar sus scripts, corriendo contra `npm run dev` (puerto 3111, gate inactivo sin `ADMIN_PASSWORD`).

- [ ] **Step 1: Crear `lib/auth.ts`**

```ts
/**
 * Autenticación liviana del panel (mecanismo replicado de Solvia).
 *
 * Este módulo es agnóstico del runtime (no importa `next/headers` ni nada de
 * node) para poder usarse tanto desde el proxy (edge) como desde server
 * components y server actions (node). La lectura de cookies vive en
 * `lib/guard.ts`, que sí es server-only.
 *
 * La sesión es una cookie firmada con HMAC-SHA256. No hay usuarios: es un
 * único acceso por contraseña, suficiente para una demo de portfolio.
 */

export const COOKIE_NAME = "vendra_sesion";
const SESSION_TTL_MS = 7 * 24 * 60 * 60 * 1000; // 7 días

function adminPassword(): string | undefined {
  return process.env.ADMIN_PASSWORD || undefined;
}

/**
 * Secreto para firmar la cookie (HMAC), independiente de la contraseña.
 * Sin SESSION_SECRET cae a ADMIN_PASSWORD para no romper desarrollo; en
 * producción conviene una SESSION_SECRET propia así rotar la contraseña no
 * invalida las sesiones firmadas (y viceversa).
 */
function secretoSesion(): string | undefined {
  return process.env.SESSION_SECRET || adminPassword();
}

/**
 * Si el gate está activo:
 * - En producción SIEMPRE (fail-closed: si falta la contraseña, nadie entra,
 *   para que un deploy sin configurar no exponga el panel).
 * - En desarrollo, solo si hay contraseña configurada, así el dev diario no
 *   queda bloqueado cuando no se necesita.
 */
export function gateActivo(): boolean {
  if (process.env.NODE_ENV === "production") return true;
  return Boolean(adminPassword());
}

function aHex(buf: ArrayBuffer): string {
  return Array.from(new Uint8Array(buf))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
}

function comparacionConstante(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let dif = 0;
  for (let i = 0; i < a.length; i++) dif |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return dif === 0;
}

async function firmar(mensaje: string, secreto: string): Promise<string> {
  const enc = new TextEncoder();
  const clave = await crypto.subtle.importKey(
    "raw",
    enc.encode(secreto),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"],
  );
  const firma = await crypto.subtle.sign("HMAC", clave, enc.encode(mensaje));
  return aHex(firma);
}

/** Token de sesión: "<expiraMs>.<hmac(expiraMs)>". Null si no hay secreto. */
export async function crearTokenSesion(): Promise<string | null> {
  const secreto = secretoSesion();
  if (!secreto) return null;
  const expira = String(Date.now() + SESSION_TTL_MS);
  return `${expira}.${await firmar(expira, secreto)}`;
}

export async function verificarTokenSesion(
  token: string | undefined | null,
): Promise<boolean> {
  const secreto = secretoSesion();
  if (!secreto || !token) return false;
  const [expira, firma] = token.split(".");
  if (!expira || !firma) return false;
  if (!/^\d+$/.test(expira) || Number(expira) < Date.now()) return false;
  return comparacionConstante(firma, await firmar(expira, secreto));
}

/** Compara la contraseña ingresada con la configurada, en tiempo constante. */
export function passwordCoincide(input: string): boolean {
  const esperada = adminPassword();
  if (!esperada) return false;
  return comparacionConstante(input, esperada);
}

export const SESSION_MAX_AGE_SECONDS = SESSION_TTL_MS / 1000;
```

```ts
// Server-only: importa next/headers, que ya impide su uso desde el cliente.
import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import { COOKIE_NAME, gateActivo, verificarTokenSesion } from "./auth";

/** ¿La request actual tiene sesión válida? (true si el gate está inactivo) */
export async function haySesion(): Promise<boolean> {
  if (!gateActivo()) return true;
  const store = await cookies();
  return verificarTokenSesion(store.get(COOKIE_NAME)?.value);
}

/** Para server components: redirige al login si no hay sesión. */
export async function protegerPagina(): Promise<void> {
  if (!(await haySesion())) redirect("/login");
}

/**
 * Para server actions: lanza si no hay sesión. Las actions pueden invocarse
 * por POST directo, así que no alcanza con el proxy de ruta.
 */
export async function exigirSesion(): Promise<void> {
  if (!(await haySesion())) throw new Error("No autorizado");
}
```

```ts
"use server";

import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import {
  COOKIE_NAME,
  crearTokenSesion,
  passwordCoincide,
  SESSION_MAX_AGE_SECONDS,
} from "@/lib/auth";

// Solo destinos internos, para evitar open redirects.
function destinoSeguro(from: unknown): string {
  const valor = typeof from === "string" ? from : "";
  return valor.startsWith("/") && !valor.startsWith("//") ? valor : "/";
}

export async function ingresar(formData: FormData) {
  const password = String(formData.get("password") ?? "");
  const from = String(formData.get("from") ?? "");
  const destino = destinoSeguro(from);

  if (!passwordCoincide(password)) {
    const qs = new URLSearchParams({ error: "1" });
    if (from) qs.set("from", from);
    redirect(`/login?${qs.toString()}`);
  }

  const token = await crearTokenSesion();
  if (token) {
    const store = await cookies();
    store.set(COOKIE_NAME, token, {
      httpOnly: true,
      sameSite: "lax",
      secure: process.env.NODE_ENV === "production",
      path: "/",
      maxAge: SESSION_MAX_AGE_SECONDS,
    });
  }

  redirect(destino);
}
```

- [ ] **Step 1: Crear `proxy.ts` en la raíz**

```ts
import { NextRequest, NextResponse } from "next/server";
import { COOKIE_NAME, gateActivo, verificarTokenSesion } from "@/lib/auth";

// Primera barrera: protege todo el panel a nivel de ruta. Las páginas y las
// server actions además re-chequean la sesión (defensa en profundidad).
export default async function proxy(req: NextRequest) {
  if (!gateActivo()) return NextResponse.next();

  const token = req.cookies.get(COOKIE_NAME)?.value;
  if (await verificarTokenSesion(token)) return NextResponse.next();

  const url = new URL("/login", req.url);
  url.searchParams.set("from", req.nextUrl.pathname);
  return NextResponse.redirect(url);
}

export const config = {
  // Matcher negativo: las rutas nuevas nacen protegidas.
  matcher: ["/((?!login|_next/static|_next/image|icon.svg|favicon.ico).*)"],
};
```

```js
  const browser = await chromium.launch({ channel: "chrome", headless: true });
  const ctx = await browser.newContext();
  const page = await ctx.newPage();

  // 1. Sin sesión → redirect con from
  await page.goto(BASE + "/pedidos");
  await page.waitForURL("**/login?from=%2Fpedidos");

  // 2. Contraseña incorrecta preserva from
  await page.getByLabel("Contraseña").fill("nop");
  await page.getByRole("button", { name: "Ingresar" }).click();
  await page.waitForURL("**/login?error=1&from=%2Fpedidos");
  assert.ok(await page.locator('p[role="alert"]').isVisible());

  // 3. Contraseña correcta → aterriza en el from
  await page.getByLabel("Contraseña").fill("vendra2026");
  await page.getByRole("button", { name: "Ingresar" }).click();
  await page.waitForURL(BASE + "/pedidos");

  // 4. Cookie adulterada → afuera
  const cookies = await ctx.cookies(BASE);
  const sesion = cookies.find((c) => c.name === "vendra_sesion");
  const valorRoto =
    sesion.value.slice(0, -1) + (sesion.value.endsWith("0") ? "1" : "0");
  await ctx.clearCookies();
  await ctx.addCookies([{ ...sesion, value: valorRoto }]);
  await page.goto(BASE + "/clientes");
  await page.waitForURL("**/login?from=%2Fclientes");

  // 5. Login de nuevo y logout → todo protegido otra vez
  await page.getByLabel("Contraseña").fill("vendra2026");
  await page.getByRole("button", { name: "Ingresar" }).click();
  await page.waitForURL(BASE + "/clientes");
  await page.locator("aside").getByRole("button", { name: "Cerrar sesión" }).click();
  await page.waitForURL("**/login");
  await page.goto(BASE + "/productos");
  await page.waitForURL("**/login?from=%2Fproductos");

  console.log("e2e auth: OK");
  await browser.close();
})().catch((e) => {
  console.error(e);
  process.exit(1);
});
```
